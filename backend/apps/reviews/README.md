
## Savol-javob

`Question`: xaridor (mehmon ham) savol beradi — `POST /products/{slug}/questions`; saytda faqat javob berilgan
savollar ko'rinadi (`GET`), muallif o'z javobsiz savolini ham ko'radi. Xodim: `/admin/questions` (javob,
yashirish), `/admin/questions/summary` — javob kutayotganlar soni.
